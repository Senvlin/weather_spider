# 课题用

用于[课题](https://github.com/cuixy09/smart-light-system)内部的天气爬取，爬取的是[这个网站](https://datashareclub.com/weather)

课题中使用的版本阉割掉了csv导出

本脚本用[uv](https://github.com/astral-sh/uv)管理虚拟环境

## How to use

1. 先确保你有python和uv
2. 下载源码,解压缩到你喜欢的地方
3. cd到相关目录，然后`uv sync`即可
 > 别忘了`./Scripts/activate`
4. 用`py main.py` 尝尝鲜

然后导出的csv文件在你电脑的**下载目录**里
